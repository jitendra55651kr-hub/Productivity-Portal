Lekin agar aap chahte hain ki Working Days aur Target Points date change karne par automatically aur exact calculate hon (including Sat/Sun exclusion), toh aap script me ye simple update add kar sakte hain: Automated Working Days & Target Logic (Code Snippet) Is Javascript function se date filter update karte hi Saturdays aur Sundays automatically minus ho jayenge: JavaScript // Date Range se Working Days (Excluding Sat/Sun) Calculate karna function getWorkingDays(startDateStr, endDateStr) { let start = new Date(startDateStr); let end = new Date(endDateStr); let count = 0; let cur = new Date(start); while (cur <= end) { const dayOfWeek = cur.getDay(); // 0 = Sunday, 6 = Saturday if (dayOfWeek !== 0 && dayOfWeek !== 6) { count++; } cur.setDate(cur.getDate() + 1); } return count; } // Target Points Recalculation Function function updateTargetAndDays() { const fromDate = document.getElementById("from-date").value; const toDate = document.getElementById("to-date").value; // Working days exclude Sat/Sun const workingDays = getWorkingDays(fromDate, toDate); const targetPerAgent = workingDays * 300; // 300 points/day rule // Update Working Days Card document.getElementById("card-working-days").innerText = workingDays; // Update Target for all Active Agents agentsData.forEach(agent => { agent.target = targetPerAgent; }); // Dashboard Table & Summary Update renderDashboard(); } Iska Fayda: Agent Delete Karne Par: Sirf active agents ka total count aur points update honge, date range tab bhi bilkul 17 days (ya 5,100 Target) hi rahegi. Check karein ki Sheet link public (Anyone with link) hai ya nahi."); } } // CSV text ko Agent Data object me convert karne ka Helper Function function parseCSVToJSON(csvText) { const lines = csvText.split('\n'); const result = []; // Header row ko chhod kar 2nd line se read karna for (let i = 1; i < lines.length; i++) { if (!lines[i].trim()) continue; // CSV quotation marks ("") clean karna const cols = lines[i].split(',').map(col => col.replace(/^"|"$/g, '').trim()); // Google Sheet ke Column order ke according map karein: // Col 0: Agent Name, Col 1: Videos, Col 2: Camps, Col 3: FDB if (cols[0]) { const videos = parseInt(cols[1]) || 0; const camps = parseInt(cols[2]) || 0; const fdb = parseInt(cols[3]) || 0; // Points calculation formula (5pt per video, 4pt per camp, 3pt per fdb) const achieved = (videos * 5) + (camps * 4) + (fdb * 3); result.push({ name: cols[0], videos: videos, camps: camps, fdb: fdb, achieved: achieved, target: 5100 // Dynamic Working Days Target }); } } return result; } Step 3: Button par Event Bind Karein "Fetch Data Live" button ke onclick event par is function ko connect kar dein: HTML Is Method Ke Advantages: No API Key Required: Google Cloud Console ya API Keys generate karne ki zaroorat nahi hai.
